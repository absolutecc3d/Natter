how do i set this up?

Enable Anonymous Authentication and create a Firestore database in your Firebase project.

Use these Firestore Rules:

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {

    match /messages/{message} {
      allow read: if request.auth != null;

      allow create: if request.auth != null
        && (
          !exists(/databases/$(database)/documents/server/settings)
          || get(/databases/$(database)/documents/server/settings).data.disableChat != true
          || (
            exists(/databases/$(database)/documents/server/claim)
            && get(/databases/$(database)/documents/server/claim).data.ownerId == request.auth.uid
          )
        );
    }

    match /presence/{presenceId} {
      allow read, create, update, delete:
        if request.auth != null;
    }

    match /server/claim {
      allow read: if request.auth != null;

      allow create: if request.auth != null;

      allow update: if request.auth != null
        && resource.data.ownerId == null
        && request.resource.data.ownerId == request.auth.uid;

      allow delete: if request.auth != null
        && resource.data.ownerId == request.auth.uid;
    }

    match /server/settings {
      allow read: if request.auth != null;

      allow create, update: if request.auth != null;

      allow delete: if request.auth != null
        && resource.data.ownerId == request.auth.uid;
    }
  }
}

Then create:

server
└── settings
    ├── serverName: "general"
    └── disableChat: false

disableChat must be a Boolean.

Use true to make the chat owner-only and false to allow everyone to chat.

There is intentionally no button in Natter for changing this. It is controlled through Firestore.
