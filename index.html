how do i set this up?
  1. Open Firebase Console .
  2. Create or open a Firebase project.
  3. Add a Web app.
  4. Copy the Firebase config and paste it above.

Enable Anonymous Authentication:

  1. Open Authentication.
  2. Open Sign-in method.
  3. Enable Anonymous.

Create Firestore:

  1. Open Firestore Database.
  2. Create the database.
  3. Open the Rules tab.
  4. Replace the rules with these:
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {

    match /messages/{message} {
      allow read: if request.auth != null;

      allow create: if request.auth != null
        && (
          get(/databases/$(database)/documents/server/settings).data.disableChat != true
          || get(/databases/$(database)/documents/server/claim).data.ownerId == request.auth.uid
        );
    }

    match /presence/{presenceId} {
      allow read, create, update, delete:
        if request.auth != null;
    }

    match /server/claim {
      allow read: if request.auth != null;

      allow create: if request.auth != null;

      allow update: if request.auth != null
        && resource.data.ownerId == null
        && request.resource.data.ownerId == request.auth.uid;

      allow delete: if request.auth != null
        && resource.data.ownerId == request.auth.uid;
    }

    match /server/settings {
      allow read: if request.auth != null;

      allow create: if request.auth != null
        && get(/databases/$(database)/documents/server/claim).data.ownerId == request.auth.uid;

      allow update: if request.auth != null
        && get(/databases/$(database)/documents/server/claim).data.ownerId == request.auth.uid;

      allow delete: if request.auth != null
        && get(/databases/$(database)/documents/server/claim).data.ownerId == request.auth.uid;
    }

  }
}

Click Publish.

Server name: 

server
└── settings
    └── serverName: "general"
    └── disableChat: false

Change serverName to change the channel name.

Change disableChat to true to make the chat owner-only.

Claim your server:

  1. Use Natter's claim button.
  2. Create server → claim.
  3. Put Natter's generated code into the code field.
  4. Natter will verify it and save your Firebase UID as the owner.

Owner messages: 

owner: true

Owner messages keep their 👑 tag after reloading.

The chat lock is enforced by Firestore Rules, so users cannot bypass it by writing directly to Firebase.
